Codex额度条 1.0.2
里奥Leo @staley_leo

安装
将“Codex额度条.app”拖到 Applications。若已运行旧额度条，请自行退出旧额度条后启动新版，无需退出 Codex。
本包适用于 macOS 13 或更新版本，含 Apple Silicon 与 Intel 两种架构。使用预构建应用不需要 Xcode、Python、Node 或开发工具。Intel 与 macOS 13 新机器尚未实测；Codex 本身另有系统和硬件要求。

首次使用
需要本机存在可运行且已登录的 Codex CLI。额度条会寻找 CODEX_USAGE_MINI_CODEX_PATH 指定的 CLI、系统或用户 Applications 中 ChatGPT/Codex 自带 CLI、Homebrew 常见目录，以及启动环境 PATH 中的 CLI。自定义路径必须是可执行文件的绝对路径。
额度读取使用所选 CLI 的登录账户，应用不校验该账户是否与 Codex GUI 账户一致。ChatGPT.app 可提供 CLI；窗口旁入口需要 Codex.app 正在运行且有可见窗口，仅跟随 com.openai.codex。
窗口跟随主要使用系统窗口信息；辅助功能仅在已授权时补充。应用不会主动申请或代替你更改系统权限。如需授权，请在系统设置中手动处理。
菜单栏图标可打开菜单、显示/隐藏额度条或查看诊断信息。启动和再次打开不自动弹诊断。首次默认浅色，可在主题色菜单切换。
入口跟随 Codex 窗口；悬停查看额度，右键调整位置。普通原生弹窗可能被入口覆盖，这是浮动层的已知取舍。切离、最小化或关闭宿主时隐藏。

签名与安全
本包仅作 ad-hoc 本地签名，没有 Apple Developer ID 签名、没有 Apple 公证，不是苹果认证应用。下载后首次打开可能被 Gatekeeper 阻止。请遵循 macOS 正常安全提示与系统允许流程，由收件人决定是否信任应用；不需要关闭系统安全保护。

数据与来源
额度仅通过本机官方 account/read、account/rateLimits/read 读取，不向 AIHOT 发送账户数据。公开消息来自 AIHOT；活动消息不代表本人额度已经重置或收到重置卡。应用在自己的 Application Support 目录保存显示设置及公开消息缓存，不随安装包携带个人数据。
本应用为独立第三方工具，非 OpenAI 官方产品。项目 MIT 与完整第三方许可见源码仓库；应用 Resources 中保留第三方许可文件。

图标与历史
采用用户选定的2号加粗圆润仪表盘，保留透明背景，不叠加第二个表盘。1.0.2 补齐历史时间：可靠发生日期优先，缺失时使用明确标注的确认时间/确认日期；历史按北京时间显示，确认不是实际到账。仍只显示最近一条，不改变活动未读规则。
